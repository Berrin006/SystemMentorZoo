# 🦁 Systementor Zoo

En modern, responsiv och användarvänlig webbplats för ett fiktivt zoo – skapad med fokus på ren design, tillgänglighet och snygg bento-grid-layout.

## 🌿 Om projektet

Systementor Zoo är en webbplats framtagen för att erbjuda besökare en varm, naturnära och engagerande upplevelse. Sidan presenterar djurparkens invånare, aktuella aktiviteter, lekplatser, restauranger samt en besöksguide och ett interaktivt nyhetsbrevsformulär.

### ✨ Funktioner
* **Modern Bento-Grid Layout:** Asymmetrisk och visuellt tilltalande struktur där lejonet och papegojan ramar in skogens djur (varg och älg) i mitten.
* **Fullt Responsiv:** Optimerad för både desktop, surfplatta och mobil med smidig anpassning utan oönskad horisontell scroll.
* **Tillgänglig (WCAG-anpassad):** Byggd med semantisk HTML5, aria-attribut och en inbyggd "hoppa till innehållet"-länk för skärmläsare.
* **Interaktiva element:** Mobilanpassad meny och JavaScript-validering för nyhetsbrevsformuläret.

---

## 🛠️ Teknikstack
* **HTML5** (Semantisk struktur)
* **CSS3** (Grid, Flexbox, moderna variabler och custom styling)
* **JavaScript (ES6+)** (Hantering av mobilmeny, dynamiskt årtal och formulärvalidering)
* **Google Fonts** (DM Sans & Manrope)

## 🚀 Kom igång (Lokal körmiljö)
Följ dessa enkla steg för att köra projektet lokalt på din dator:
1. **Klona repot** (eller ladda ner koden som ZIP):
```bash
git clone https://github.com/Berrin006/SystemMentorZoo.git
```
2. **Öppna mappen** i din kodredigerare (t.ex. [VS Code](https://code.visualstudio.com/)).
3. **Starta via Live Server:**
* Installera tillägget **Live Server** i VS Code.
* Högerklicka på `index.html` och välj **"Open with Live Server"**.
